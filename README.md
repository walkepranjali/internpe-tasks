InternPE Internship Tasks – Java

About the Project

This repository contains the Java programming tasks completed during my internship at InternPE. The project focuses on strengthening core Java programming skills through console-based applications and interactive games.

Projects Included

1. Guess the Number Game

A console-based game in which the user guesses a randomly generated number.

Concepts Used:

Random number generation

Conditional statements

Loops

User input using Scanner

2. Rock Paper Scissors

A console-based implementation of the classic Rock Paper Scissors game. The user plays against the computer, and the winner is determined by the game rules.

Concepts Used:

Random number generation

Conditional statements

Switch statements

User input and output

3. Tic-Tac-Toe

A two-player console-based game played on a 3×3 grid. Players take turns marking their symbols, and the game checks for a winner or a draw.

Concepts Used:

Arrays

Loops

Conditional statements

Methods

Game logic

4. Connect Four

A console-based implementation of Connect Four in which players drop discs into a grid and try to connect four of their symbols horizontally, vertically, or diagonally.

Concepts Used:

Two-dimensional arrays

Loops and conditional statements

Methods

Board management

Win-condition checking

Technologies Used

Programming Language: Java

Development Environment: Visual Studio Code

Version Control: Git and GitHub

Application Type: Console-based applications

How to Run

Prerequisites

Install the Java Development Kit (JDK).

Configure Java in your system.

Open the project folder in Visual Studio Code or a terminal.

Compile and Run a Program

Navigate to the directory containing the Java file and execute the following commands:

javac Guess_a_number_game.java
java Guess_a_number_game

Replace the filename and class name with the corresponding names for the game you want to run.

Note: If a Java file contains a package declaration, compile and run it from the appropriate package directory.
